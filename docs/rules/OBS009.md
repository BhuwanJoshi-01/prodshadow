# OBS009 · migration-duration

| Default severity | Evidence |
|---|---|
| critical | observed |

## What it detects

The median migration duration across candidate repeats exceeds `policy.max_migration_seconds`, evaluated only when that budget is set.

## Why it matters

Useful as a regression guard for the same fixture over time. Durations scale with data size and hardware, so this is not a prediction of production time; confidence is medium at most.

## Example

Flagged:

```yaml
policy:
  max_migration_seconds: 1
```

Preferred:

```yaml
policy:
  max_migration_seconds: 30
```

## How ProdShadow verifies it

Compare reports over time with `prodshadow diff` or `prodshadow history`.

## Configuration

Change the severity or turn the rule off in `prodshadow.yaml`:

```yaml
policy:
  rules:
    OBS009: critical   # or info, warning, off
```

Suppress a reviewed case in the suppressions file (`policy.suppressions`):

```yaml
version: 1
suppressions:
  - rule: OBS009
    reason: "why this is acceptable"
    expires: 2027-06-30
```

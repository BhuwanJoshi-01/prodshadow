# PS145 · granted-to-public

| Default severity | Evidence |
|---|---|
| warning | static |

## What it detects

`GRANT ... TO PUBLIC` on tables, sequences, functions, schemas or all objects in a schema, and `ALTER DEFAULT PRIVILEGES ... GRANT ... TO PUBLIC`.

## Why it matters

`PUBLIC` means every role in the cluster: application roles, reporting users, roles of other applications that share the server, and roles created in the future. A grant meant for one consumer usually belongs to that consumer's role. Default privileges granted to `PUBLIC` extend the exposure to every table created afterwards.

## Example

Flagged:

```sql
GRANT SELECT ON customers TO PUBLIC;
```

Preferred:

```sql
GRANT SELECT ON customers TO reporting;
```

## How ProdShadow verifies it

Static only.

## Configuration

Change the severity or turn the rule off in `prodshadow.yaml`:

```yaml
policy:
  rules:
    PS145: critical   # or info, warning, off
```

Suppress a reviewed case next to the statement:

```sql
-- prodshadow:ignore PS145 reason="why this is acceptable" expires=2027-06-30
```
